规则说明

曝光事件
  • 广告实际展示后上报
  • 轮播广告首次进入可视区域上报：如 5 个轮播只看到第 1 个，只上报第 1 个
  • 首屏外广告滚动到可视区域才上报
  • 同页面按各广告位模块 positionKey + 广告 ID 去重
点击事件
  • 点击一次上报一次
  • 不做点击去重
  • 规则 ID 取接口返回值
