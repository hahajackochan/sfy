一、需求背景

会员小程序已支持个性化广告推荐能力。会员运营人员可以在后台配置分群规则、展示规则，并将不同广告关联到不同规则，实现针对不同用户群体展示不同广告内容。

当前业务只能查看广告点击相关数据，无法查看广告曝光人数和曝光次数。因此运营无法判断广告点击表现不佳到底是因为广告内容/权益不吸引目标人群，还是因为广告曝光量不足、展示规则配置不合理、目标人群覆盖过小。

二、需求目标

目标类型描述衡量指标目标值
数据采集目标新增广告曝光事件上报索数可查询广告曝光数据广告实际展示后可成功上报
归因分析目标曝光/点击事件携带广告对应规则信息事件字段包含分群规则 ID、展示规则 ID曝光与点击字段口径一致
配置效率目标地区类规则选择支持搜索地区选择控件可搜索省/市/区覆盖 3 个指定点位

三、用户与使用场景

主要用户：会员运营人员

关注不同广告内容在不同用户人群、不同展示规则下的曝光和点击效果，用于判断是否需要更换广告素材、活动权益或投放策略。

协作用户：研发/测试

关注广告查询接口是否准确返回规则信息、小程序是否按正确时机上报、索数是否能按字段筛选数据。

典型业务场景

运营为“黄金等级以上且线下下单时间在 365 天前的客户”配置专享复购优惠广告。广告上线后，运营需要知道该广告结合分群/展示规则实际展示给了多少目标用户，以及这些用户是否愿意点击，从而判断广告内容是否有吸引力。

六、详细方案：广告查询接口优化

6.1 功能说明

本期仅要求每条广告记录新增返回当前广告下，当前用户实际命中的分群规则 ID 和展示规则 ID。

接口文档：https://doc.suofeiya.com.cn/web/#/376/12833

6.2 新增返回字段

字段名字段含义类型是否必返空值规则
crowdRuleIds当前广告下用户实际命中的分群规则 IDstring是无命中返回空字符串 ""
displayRuleIds当前广告下用户实际命中的展示规则 IDstring是无命中返回空字符串 ""

6.3 字段格式规则

  1. 规则 ID 字符串统一使用 rule_ 作为固定前缀，前缀后拼接实际分群规则 ID 或展示规则 ID，如 rule_1。
  2. 命中单个规则时，返回一个带 rule_ 前缀的规则 ID，如 rule_1。
  3. 命中多个规则时，将多个带 rule_ 前缀的规则 ID 用英文逗号拼接，如 rule_1,rule_2,rule_3。
  4. 广告未关联对应规则时，返回空字符串 ""。

6.4 返回口径

每条广告记录只返回“本广告下，当前用户实际命中的规则 ID”。不得返回用户命中但与该广告无关的分群规则或展示规则。

七、详细方案：会员小程序广告曝光上报

7.1 功能说明

会员小程序在广告实际渲染并展示后，调用索数广告曝光上报事件。

7.2 曝光触发口径

广告形态/场景曝光上报规则
普通广告（单图/弹窗）广告组件实际渲染并展示后上报曝光
轮播广告广告首次进入可视区域时上报曝光。示例：如轮播图有 5 个，会员只查看了第 1 个就离开，未看到后续 4 个，则只上报第 1 个广告的曝光。
页面首屏外广告接口已返回但当前屏幕未展示时不上报；用户滚动到广告进入可视区域后才上报曝光
轮播位中未被用户看到的广告不上报曝光
接口返回但页面未展示不上报曝光
广告图片/组件加载失败不上报曝光

7.3 曝光去重规则

同一页面未离开前，每个广告位模块使用各自独立的广告位置标识，并按“广告位置标识 + 广告 ID”避免重复上报。

对于页面底部或首屏外广告，即使广告接口已返回该广告记录，只要当前手机屏幕未滚动到对应位置、用户实际未看到广告，就不得上报曝光；需等用户滚动到该广告进入可视区域后才上报。该类广告按“可视状态变化”触发：从不可见变为可见时上报；

八、详细方案：广告点击上报迁移至索数

8.1 功能说明

会员小程序现有广告点击事件已具备上报能力，但当前上报到小程序 WE 分析，且未携带分群规则 ID、展示规则 ID。本期需将广告点击事件调整为上报到索数，并在索数点击事件中补充分群规则 ID 和展示规则 ID。

8.2 点击规则

  1. 点击事件不做去重，用户点击一次广告，上报一次索数点击事件。
  2. 点击事件需停止依赖小程序 WE 分析作为本需求的数据分析口径，统一上报到索数。
  3. 索数点击事件使用该广告记录中接口返回的 crowdRuleIds 和 displayRuleIds。
  4. 曝光和点击应使用同一份广告对象里的规则 ID，保证字段口径一致。
  5. 广告 ID、广告位置标识等原有点击字段需按索数事件字段要求传入。

8.3 点击上报字段变化与索数上报说明

点击事件沿用现有触发时机和不去重规则，但上报目标由小程序 WE 分析调整为索数，并在索数事件字段中补充分群规则 ID 和展示规则 ID。

九、详细方案：后台地区选择支持搜索

9.1 功能说明

为提升分群规则和展示规则配置效率，涉及地区选择的控件需支持搜索。用户可通过输入省、市、区关键字快速定位并选择目标地区。

9.2 涉及点位

模块路径/点位优化要求
分群规则管理属性 - 通用属性 - 位置地区选择支持搜索
分群规则管理线下订单 > 下单 - 安装省市区地区选择支持搜索
展示规则管理地区限制地区选择支持搜索

9.3 交互要求

  1. 支持按省、市、区名称关键字搜索。
  2. 搜索结果需展示完整层级，避免同名地区误选。
  3. 搜索后选择地区，不影响原有地区层级选择逻辑。
  4. 无搜索结果时展示空状态提示。

十一、异常与边界处理

场景处理规则
广告接口请求失败不展示广告，不上报曝光
广告接口返回空列表不上报曝光
接口返回广告但页面未渲染不上报曝光
广告图片或组件加载失败不上报曝光
轮播广告未进入可视区域不上报曝光
页面首屏外广告未滚动到可视区域不上报曝光
页面首屏外广告滚动进入可视区域从不可见变为可见时上报一次；停留可视区不重复上报；离开后再次进入可再次上报
同页面广告组件重复渲染按各广告位模块独立的广告位置标识 + 广告 ID 去重，同一组合只上报一次曝光
用户离开页面后重新进入广告再次实际展示时可重新上报曝光
分群规则 ID 为空接口返回空字符串；索数上报空字符串
展示规则 ID 为空接口返回空字符串；索数上报空字符串

展示规则 IDdisplayRuleIds是广告查询接口新增返回字段rule_101,rule_102

12.2 点击事件

现有广告点击事件由小程序 WE 分析上报调整为上报到索数，并补充分群规则 ID、展示规则 ID，取值与曝光事件一致。

12.3 索数使用方式

由于多个规则 ID 使用英文逗号拼接到同一字段，索数中可通过“字段包含指定规则 ID”的方式筛选指定分群规则或展示规则下的曝光/点击数据。
